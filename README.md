# Wayfarer — The Forever Tome

A guild interest page for the planned Wayfarer addon for WoW: Forever.

This repository contains the public website only. It is not an addon release.

## Website

Publish the `main` branch root with GitHub Pages. `index.html` is a standalone page with no build step or external dependencies.

The page offers a short pitch, expandable planned feature descriptions, illustrative tooltip previews, and a feedback form. Responses can be copied into guild chat or posted as public GitHub issues. The static page itself does not collect or store answers and includes no analytics.

The feature descriptions are plans, not a released-feature listing. Photos, peer/event verification, physical controller acceptance and supported Hardcore functionality retain technical gates.
