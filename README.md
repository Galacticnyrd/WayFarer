# Wayfarer — The Forever Tome

A guild interest page for the planned Wayfarer addon for WoW: Forever.

This repository contains the public website only. It is not an addon release.

## Website

Publish the `main` branch root with GitHub Pages. `index.html` and the `assets/` folder require no build step or external dependencies.

The page offers a short pitch, expandable planned feature descriptions, illustrative tooltip previews, a feedback form, and the optional looping website score with playback and volume controls. Visitors can choose whether they would try Wayfarer, select up to three favorite features, and add a suggestion. The form opens a consistently titled public GitHub issue draft with separate sections for each answer; visitors review and submit the issue on GitHub. The static page does not collect or store answers and includes no analytics.

The feature descriptions are plans, not a released-feature listing. Photos, peer/event verification, physical controller acceptance and supported Hardcore functionality retain technical gates.
