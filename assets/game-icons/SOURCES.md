# Game icon sources for the local Tome concept

These are 56 × 56 World of Warcraft inventory icon files served by the Wowhead image CDN (`https://wow.zamimg.com/images/wow/icons/large/`). Names and categories were matched against [Warcraft Wiki's WoW icon catalog](https://warcraft.wiki.gg/wiki/Warcraft_Wiki:WoW_Icons). The bronze item socket is original SVG artwork in this directory.
